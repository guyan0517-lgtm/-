# 密友联机与多人跑团第一阶段实施方案

根据要求，本阶段聚焦核心基础功能：完成长连接搭建、密友添加与双人即时通信、拉入群聊配置公共守秘人KP、中文括号场外发言屏蔽，以及AI双真人玩家身份识别。

## 一、第一阶段核心目标

1. 服务端长连接与密友添加
在服务端集成轻量长连接，每台设备分配专属密友码。
在添加好友界面新增两字功能：密友。
输入对方密友码即可建立永久密友关系，支持双方一对一实时通信。

2. 多人跑团群聊创建与同步
支持将密友拉入跑团群聊，并在群内配置公共守秘人KP。
群内任意玩家发言，通过长连接即时同步给对方。

3. 中文括号场外发言过滤机制
当玩家发送的气泡整体以中文括号包裹时，该条消息被判定为真人场外对白，系统组装AI上下文时自动彻底屏蔽该条消息，AI完全不可见。
若气泡外侧带有其他文字，或者由AI自身发出，则不触发屏蔽。

4. AI提示词与双真实玩家认知
在系统提示词中明确标识本群存在两名不同的真实人类玩家，分别列出两名玩家的姓名。
加入绝对禁令：AI守秘人绝对禁止扮演或代发两名人类玩家的消息，必须只专注于以守秘人或NPC身份进行回应。

## 二、具体执行步骤

1. 安装基础依赖包并升级服务端长连接通信中继。
2. 编写前端实时同步管理器，处理设备识别码、密友互加、消息收发与断线重连。
3. 在添加好友界面挂载密友入口与绑定弹窗。
4. 在群聊消息流与发送逻辑中对接长连接广播与中文括号过滤。
5. 在AI提示词生成逻辑中加入双真人玩家识别与禁止代演约束。
