# 思维方案

针对历史上下文折叠导致模型误判思维链字数以及漏填照抄现象，构建历史占位说明强化与动态末尾警告机制。

## 决策与规则

> [!IMPORTANT]
> 经明确，历史折叠采用系统说明强化策略，并在检测到上一轮未生成或照抄折叠文本时于提示词末尾注入强力警告。

- 历史占位说明：将原有的简短占位替换为明确的系统折叠公告，阐明此处曾包含完整深度推演且由系统折叠，严禁当前轮次复述或照抄
- 动态违规判定：针对上一轮回复进行多维检查，若未提供思考内容、思考内容过短、或直接照抄系统折叠占位文本，判定为思维链缺失
- 尾部强制警告：检测命中违规时，在上下文尾部注入最高优先级的系统警告，强制要求当前轮次完整推演

## 1. 概述与核心逻辑

模型在读取历史消息时，若历史思考字段仅显示简短提示，容易形成当前也可简短输出的错误模仿倾向，甚至直接复述折叠文字。
本方案从两端阻断该问题：
前端构建上下文时，重构历史折叠占位文案，明示其仅为系统为了节省长度而隐藏真实推演的标记。
在组装发给模型的请求上下文时，增加针对上一轮回复的自动化合规检验。若上一轮未填、渲染失败或照抄占位符，即刻在最尾部追加醒目警告，纠正偷懒行为。

## 2. 交互体验与流程设计

整体流程全自动运行，无需用户手动介入：

```
┌───────────────────────────┐

│ 将历史思考替换为系统折叠公告 │

              │
              ▼
┌───────────────────────────┐
│    上一轮思维链有效性检查   │
│ 检查项：是否为空、是否过短、 │
│ 是否与系统折叠占位词高度雷同 │
└─────────────┬─────────────┘
              │
      ┌───────┴───────┐
      ▼               ▼
   [合格]          [违规]

```

## 3. 关键实现决策与权衡

- 决策一：历史记录中的占位提示文本
  改动方式：将原有的简略文本修改为明确告知模型这是已生成完整推演后的系统归档标记，并禁止复述。
  原因：消除模型的模仿简略偏见，使其理解历史推演真实存在。

- 决策二：违规判定的覆盖范围
  判定维度：包含无思考字段、思考字段无法解析、思考字段内容小于规定长度、以及思考字段包含折叠公告特征词。
  原因：彻底防范模型因为格式错误、完全不写或复制上下文而蒙混过关。

- 决策三：警告注入的位置
  注入位置：在全部历史对话之后、紧邻模型当前生成起点的末尾系统消息处。
  原因：大语言模型对上下文末尾的指令具有最高注意力响应度，能有效迫使模型重新展开思考。

## 4. 技术实施步骤

- 第一步：在单聊与群聊的历史消息转换代码中，更新折叠文本为系统折叠公告。
- 第二步：在构建发送载荷阶段，编写专门的上一轮思维链检测逻辑，抽取最近一条助手回复进行合规审查。
- 第三步：若审查发现未生成、渲染异常或抄袭占位词，在载荷尾端压入带有强制约束的系统警告消息。
