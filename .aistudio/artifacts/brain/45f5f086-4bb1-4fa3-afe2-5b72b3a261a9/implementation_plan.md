# AI写模组因地制宜四阶流水线方案

## 一、核心设计原则：因地制宜，看菜下碟

不同题材的模组需要截然不同的灵魂，绝不强行给所有故事套上反转或固定结构：
- **深情、悲情、唯美浪漫、宿命救赎向**：不需要生硬反转或刻意抓马，核心在于极致的氛围感渲染、光影季节与感官细节的流动、欲言又止的克制深情、以及一步步推向情绪高潮的宿命美学。
- **日常、茶番、甜宠、贴贴、旅游向**：不需要恐怖黑幕或复杂诡计，核心在于鲜活有趣的相处切面、巧妙的亲密处境、让人会心一笑的互动细节与生活温度。
- **粉红、拉扯、强制、训犬、修罗场向**：核心在于双层人设反差、权力博弈、感官张力与进退两难的暧昧抉择。
- **悬疑、怪谈、解密、循环、硬核向**：核心在于草蛇灰线的伏笔、叙事诡计、合理反转与严密的线索闭环。

---

## 二、明确的多AI四阶分工流水线

1. **前置可选开关：抽选**
   - 界面提供独立的 **抽选** 勾选框。勾选时从对应题材风味的灵感池中抽取五组底牌供AI1挑选融合；不勾选时完全由AI1根据你选的标签自主思考破题。

2. **AI1：审题破局与底牌立意构思**
   - 引导AI1先审视你勾选的标签组合，思考这个主题真正打动人心的核心是什么，枪毙平庸俗套的初稿点子，写出《守秘人底牌与核心立意》《猫与HO隐藏设定》以及最契合该主题的叙事脉络大纲。

3. **AI2：因地制宜深化与叙事调度**
   - 接手AI1的大纲，根据题材属性自动切换深化方向：浪漫悲情向重点铺陈五感氛围、意象呼应与情绪递进；悬疑怪谈向重点编织伏笔、插叙倒叙、红鲱鱼与反转；拉扯粉红向重点设计互动博弈小机制与人物失控节点；同时提取配套调查地点地图节点与关键线索卡。

4. **AI3：玩家视角盲测挑刺与节奏修补**
   - 扮演未读过底牌的玩家通读AI2的流程，检查悬疑伏笔是否过于显眼、浪漫氛围是否沦为空洞口号、节奏哪里拖沓需要删减、哪里值得扩写细节，并将修补意见合入终版分章细纲。

5. **AI4：融合本地思维链分批生成全文**
   - 结合你勾选的本地思维链预设中的文风与叙事规范，分批次逐章写出完整模组：包括唯一公开展示的 `00-模组已知信息`、后台加密封存的 `01-幕后真相与机制`、`02-模组导读与大纲`、`猫与人设专属章`、带防KP越界截断指令的 `分幕事件章` 以及 `结局分歧章`，完成后一键存入本地模组库。
